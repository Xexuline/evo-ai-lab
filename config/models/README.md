# Perfiles de modelos

Este directorio se reserva para perfiles declarativos que consumirá `evo-model`. Un perfil deberá describir identificador, backend, ruta local del modelo, contexto, MTP y opciones de servidor, sin incluir modelos GGUF, tokens ni otros secretos.

El perfil activo actual está representado de forma fiel por `scripts/llama-qwen38.sh`; todavía no se ha convertidoido a un formato nuevo para no crear dos fuentes de verdad.
